# Loja API

Projeto de uma API REST para cadastro de produtos, desenvolvido com Java, Spring Boot e PostgreSQL.

## Funcionalidades

- Cadastrar produtos
- Listar produtos cadastrados
- Editar produtos
- Excluir produtos
- Interface web simples com HTML, CSS e JavaScript

## Tecnologias utilizadas

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- HTML
- CSS
- JavaScript

## Como executar o projeto

Antes de rodar o projeto, é necessário ter o PostgreSQL instalado e criar um banco de dados chamado:

```sql
